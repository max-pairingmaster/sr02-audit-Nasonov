## 📋 Опис проєкту

**CafeOrders** — консольний сервіс для управління замовленнями, розрахунку рахунків, знижок, промокодів та сервісних зборів у кафе.

Репозиторій демонструє повний цикл роботи з успадкованим кодом (legacy code):
1. **Інвентаризація та аудит якості** успадкованого коду (вимірювання LOC, CC, вкладеності).
2. **Формування реєстру дефектів проєктування** (Code Smells).
3. **Створення страхувальної сітки характеризаційних тестів** (xUnit) із прорізанням швів (Seams).
4. **Покроковий рефакторинг** за принципом «1 рефакторинг = 1 комміт».
5. **Доказ незмінності поведінки** та оцінка залишкового технічного боргу.

---

## 🏷️ Структура тегів репозиторію

- `baseline` — початковий стан успадкованого коду (Джерело А, 452 LOC, CC=14 у `MenuService.Total`).
- `safety-net` — створено 12 характеризаційних тестів xUnit, прорізано шов часу `DateTimeOffset? now = null`.
- `after-refactoring` — кінцевий стан після виконання всіх 12 запланованих рефакторингів (CC знижено до 4).
